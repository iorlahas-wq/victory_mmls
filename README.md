# Victory_MMLS

Victory Multimedia Learning System (MMLS)

A simple web-based multimedia learning system for vocational skills acquisition.

## Planned stack

- PHP
- MySQL
- HTML/CSS
- JavaScript
- Bootstrap
- XAMPP

## Database convention

All table primary keys use:

`INT UNSIGNED AUTO_INCREMENT PRIMARY KEY`

Foreign-key columns use the same `INT UNSIGNED` type.
